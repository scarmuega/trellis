# 0000 — Adopt Trellis

This domain adopts the Trellis operating model (<ref: trellis spec>). The
spec version this root operates against is pinned in `trellis.toml`
(`spec = N`); lint item 18 tracks it against the kernel's. Deviations from
the spec require a decision in this directory. Decisions are append-only:
supersede, never edit.
